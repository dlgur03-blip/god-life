> **버전:** v2.0 | **작성일:** 2026-03-03 | **작성:** AI 보조

## 1. 사업 개요

### 1.1 서비스명
**GOD LIFE MAKER (갓생메이커)**

### 1.2 한 줄 요약
> AI가 매일의 대화를 통해 목표 설정부터 실행까지 모든 것을 함께 채워주는, 과학 기반 올인원 자기계발 플랫폼

### 1.3 미션
"매일 아침, 반드시 이 사이트에 들어오세요. 당신은 분명 갓생을 살게 될 것입니다."

사용자가 흩어진 목표, 습관, 재무, 건강, 감정을 하나의 시스템에서 관리하고, AI 코치와 대화를 통해 자연스럽게 모든 모듈을 채워나가며 실행력을 극대화하는 서비스.

### 1.4 핵심 가치
| 가치 | 설명 |
|------|------|
| **AI 코칭** | 대화를 통해 목표·계획·기록을 자동으로 채워주는 AI 파트너 |
| **과학 기반** | 모든 모듈이 심리학·뇌과학 연구로 검증된 방법론 기반 |
| **올인원** | 목표·습관·일지·재무·건강·동기분석을 하나의 플랫폼에 |
| **바이럴 설계** | 비로그인 심리검사(MET)로 자연스러운 사용자 유입 |
| **글로벌** | 한국어·영어·일본어·중국어·힌디어 5개 언어 지원 |

| **Habitica** | 게이미피케이션 | 습관만 추적, 목표 체계 없음 | 목표→계획→실행→회고 풀사이클 |

| **ChatGPT/Claude** | 범용 AI | 데이터 지속 없음, 구조 없음 | 구조화된 모듈에 AI가 자연스럽게 통합 |
| **Coach.me** | 코칭 시스템 | 영어 전용, 비쌈 | AI 자동 코칭, 다국어, 무료 시작 |

### 2.4 우리만의 해자 (Moat)
1. **"갓생" 브랜딩**: 한국 MZ세대 문화코드를 정확히 포착한 유일한 플랫폼
2. **AI + 구조의 결합**: 빈 캔버스가 아닌, AI가 대화로 채워주는 구조화된 시스템
3. **바이럴 엔진**: MET 동기검사가 비로그인 유입 채널로 작동
4. **과학 기반 콘텐츠**: 각 모듈에 심리학·뇌과학 근거가 내장
5. **데이터 네트워크 효과**: 사용할수록 AI 분석이 정교해짐

#### 3.2.1 AI 우선순위 시스템

**초기 온보딩 플로우:**
1. **MET 동기원형검사** 수행 (이미 구축됨)
2. **실행력 자가진단 설문** (신규)
   - "하루에 자기계발에 쓸 수 있는 시간은?" (15분/30분/1시간/2시간+)
   - "지금까지 습관 형성에 성공한 경험은?" (없음/1~2개/여러개)
   - "가장 개선하고 싶은 영역은?" (목표/습관/재무/건강/감정/시간관리)
   - "아침형 vs 저녁형?" → 타임블록 최적화
   - "어떤 방식이 편한가요?" (직접 입력 vs AI 대화로 채우기)
3. **AI 진단 대화** (신규)
   - MET 결과 + 설문 답변 기반으로 AI가 맞춤 대화
   - "당신은 회피동기가 높은 방어적 성취자 유형이에요. 규율 마스터리부터 시작하면 빠르게 성과를 느낄 수 있어요."
   - 7개 모듈 중 우선 활성화할 3개 추천
4. **개인화된 대시보드** 생성
   - AI가 추천한 순서대로 모듈 강조
   - 매일 "오늘의 포커스" 알림

#### 3.2.2 AI 자동 채움 시스템

**대화 → 모듈 자동 매핑:**

| 대화 내용 | 자동 연결 모듈 | 동작 |
|-----------|---------------|------|
| "오늘 회사에서 짜증나는 일이 있었어" | 셀프 서신 | 분노 항목 자동 기입 |
| "이번 주에 운동 3번 하고 싶어" | 규율 마스터리 | 규칙 자동 생성 |
| "3개월 안에 토익 900 넘기고 싶어" | 운명 네비게이터 | 3개월→1개월→주간 목표 자동 분해 |
| "오늘 커피 5000원, 점심 12000원" | 머니 플로우 | 지출 자동 기록 |
| "요즘 잠을 못 자겠어" | 바이오 해킹 | 수면 프로토콜 추천 |
| "100일 독서 챌린지 하고 싶어" | 성공 코드 | 프로젝트 자동 생성 |

**AI 프로액티브 알림:**
- "셀프 서신을 아직 안 쓰셨네요! 오늘 하루 어땠는지 이야기해 볼까요?"
- "규율 체크가 3일째 비어있어요. 잠깐 확인해볼까요?"
- "이번 달 지출이 저번 달보다 23% 늘었어요. 함께 점검해볼까요?"
- "100일 챌린지 Day 47! 절반 가까이 왔어요. 오늘의 기록을 남겨볼까요?"

#### 3.2.3 실행력 레벨 시스템

| 레벨 | 이름 | 기준 | AI 행동 |
|------|------|------|---------|
