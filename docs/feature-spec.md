# 갓생메이커 (God Life Maker) — 사업 기능 명세서

> **버전**: 2.0
> **최종 수정**: 2026-03-04
> **핵심 컨셉**: AI 대화형 자기계발 다이어리

---

## 1. 서비스 개요

### 1.1 한 줄 정의
**"AI와 대화하면서 하루를 설계하고 기록하는 자기계발 플랫폼"**

### 1.2 핵심 플로우

```
┌─────────────────────────────────────────────┐
│                  하루의 흐름                    │
├─────────────────────────────────────────────┤
│                                             │
│  🌅 아침 (기상 후)                            │
│  ├─ AI 코치와 대화 시작                       │
│  ├─ 어제 목표 점검 ("어떻게 됐어?")            │
│  ├─ 장기 목표 상기 (궁극 → 올해 → 이번주)      │
│  ├─ 오늘 일정 확정                            │
│  ├─ 100일 프로젝트 / 루틴 상기                 │
│  └─ 꿀팁 1개 수령                             │
│                                             │
│  🌆 오후/저녁 (알림 수신)                      │
│  ├─ AI 코치와 대화 시작                       │
│  ├─ 오늘 목표 달성 여부 점검                   │
│  ├─ 하루 이야기 (깊이 있는 대화)               │
│  ├─ 셀프 서신 자동 채우기 (감사/반성/중요)      │
│  ├─ 지출 기록                                │
│  └─ 내일 방향 잡기                            │
│                                             │
└─────────────────────────────────────────────┘
```

### 1.3 차별점
| 기존 자기계발 앱 | 갓생메이커 |
|:---|:---|
| 양식에 직접 입력 | AI와 수다 떨면 자동 채워짐 |
| 매일 새로 목표 작성 | 어제 기반으로 점검 + 이어가기 |
| 습관 트래커만 존재 | 장기 비전 ↔ 오늘 일정 연결 |
| 기록 후 방치 | AI가 패턴 발견, 피드백, 꿀팁 |
| 각 기능이 분리됨 | 대화 하나로 모든 모듈 통합 |

## 2. 핵심 모듈

### 2.1 AI 갓생코치 (메인 인터페이스)

**설명**: 모든 모듈의 관문. 대화만으로 기록/계획이 완성됨.

| 항목 | 상세 |
|:---|:---|
| 위치 | 플로팅 버튼 (모든 페이지 우측 하단) |
| AI 모델 | Google Gemini 2.5 Flash Lite |
| 시간 인식 | 사용자 타임존 기반 (아침/오후/저녁 자동 구분) |
| 퀵 액션 | 아침: "하루 계획하기" / 오후: "하루 보고하기" |
| 자동 채우기 | 대화 → action block 파싱 → 모듈에 자동 저장 |
| 크레딧 | 100크레딧 무료 (약 1,000회), 0.1크레딧/호출 |
| BYOK | 개인 Gemini API 키 등록 시 무제한 무료 |

**아침 대화 흐름**:
1. 어제 목표 점검 → 성공/실패 확인
2. 장기 목표 상기 (궁극 → 연간 → 월간 → 주간)
3. 오늘 할 일 확정 → 운명 네비게이터에 자동 저장
4. 습관/루틴 체크 → 규율 마스터리 연동
5. 100일 프로젝트 진행도 상기
6. 1-2문장 꿀팁 제공

**오후 대화 흐름**:
1. 오늘 목표 달성 점검
2. 하루 이야기 (감정 탐색, 깊이 있는 대화)
3. 감사한 일 / 중요한 일 / 반성 → 셀프 서신 자동 채우기
4. 지출 기록 → 머니 플로우 자동 저장
5. 내일 방향 간단 설정

---

### 2.2 운명 네비게이터 (Destiny Navigator)

**설명**: 인생의 장기 비전 → 오늘 할 일까지 연결하는 목표 시스템.

| 필드 | 설명 |
|:---|:---|
| 궁극의 나 | 인생 최종 목표 |
| 10년 / 5년 / 3년 / 1년 | 장기 비전 |
| 6개월 / 3개월 / 1개월 | 중기 목표 |
| 2주 / 1주 | 단기 목표 |
| 오늘의 목표 | 오늘 할 일 (매일 갱신) |
| 유지할 습관 | 계속해야 할 좋은 습관 |
| 없앨 습관 | 제거해야 할 나쁜 습관 |
| 휴식 시간 | 휴식 시간 배정 |
| 타임블록 (24h) | 시간대별 계획 vs 실제 기록 |

**AI 연동 방식**:
- 매일 새로 세우지 않음 → 어제 기반으로 점검 + 이어가기
- 빈 칸은 AI가 대화로 자연스럽게 유도 (한 번에 1-2개씩)
- 장기 목표에서 단기 목표로 자연스럽게 분해
- 100일 프로젝트와 연결 ("이거 프로젝트로 만들어볼까?")

---

### 2.3 셀프 서신 (Self Epistle)

**설명**: 매일의 감정과 사건을 기록하는 일기 시스템.

| 필드 | 설명 |
|:---|:---|
| 감사 (3칸) | 오늘 고마웠던 일 |
| 중요한 일 (3칸) | 오늘의 핵심 사건 |
| 분노 | 화났던 일 (감정 해소) |
| 여가 (3칸) | 즐거웠던 일 |
| 반성 (3칸) | 돌아보기, 개선점 |

**AI 연동 방식**:
- 오후 대화에서 자동 추출 ("고마웠던 일 있어?" → gratitude 채우기)
- 사용자가 직접 입력할 필요 없음
- AI가 대화 중 자연스럽게 각 필드를 물어봄

---

### 2.4 규율 마스터리 (Discipline Master)

**설명**: 매일 지켜야 할 규칙/습관 체크리스트.

| 기능 | 설명 |
|:---|:---|
| 규칙 등록 | 최대 13개, 사용자 정의 |
| 일일 체크 | 오늘 + 어제까지 체크 가능 |
| 연속 달성 | 스트릭 카운터 |
| 인사이트 | 달성률 그래프 |

**AI 연동 방식**:
- 대화에서 습관 언급 시 규칙으로 등록 제안
- 아침에 습관 상기: "유지할 습관이 '매일 운동'이었지?"
- 달성률 축하: "와 7개 중 7개 다 했어!"

---

### 2.5 머니 플로우 (Money Flow)

**설명**: 수입/지출 기록 시스템.

| 기능 | 설명 |
|:---|:---|
| 수입/지출 등록 | 카테고리, 금액, 메모 |
| 일별 조회 | 날짜별 거래 내역 |

**AI 연동 방식**:
- "오늘 뭐 산 거 있어?" → 대화에서 지출 자동 추출
- 금액 불명확 시 AI가 확인 ("정확히 얼마였어?")
- 카테고리 자동 분류 (food, transport, etc.)

---

### 2.6 100일 프로젝트 (Success Project)

**설명**: 장기 프로젝트 관리 시스템 (100일 챌린지 등).

| 기능 | 설명 |
|:---|:---|
| 프로젝트 생성 | 제목, 시작일 |
| D-Day 카운터 | 시작일 기준 경과일 표시 |
| 일일 기록 | 매일 진행 사항 기록 |
| 활성/비활성 | 프로젝트 관리 |

**AI 연동 방식**:
- "이거 100일 프로젝트로 만들어볼까?" 제안
- 아침에 프로젝트 진행도 상기
- 목표와 자연스럽게 연결

---

### 2.7 MET 동기원형검사 (Motivation Engine Type)

**설명**: 30문항 심리검사 → AI 분석 → 개인 맞춤 동기 유형 진단.

| 기능 | 설명 |
|:---|:---|
| 30문항 검사 | 리커트, 양자택일, 시나리오, 메타포 |
| AI 분석 | Gemini가 9개 차원 분석 → 원형 생성 |
| 결과 페이지 | 레이더 차트, 상세 분석, 만트라 |
| SNS 공유 | OG 카드 이미지 + 고유 URL |
| 비로그인 | 누구나 바로 검사 가능 (바이럴 최적화) |

**바이럴 전략**:
- 비로그인 진입 → 검사 완료 → 결과 공유 → 친구 유입
- 결과 페이지에서 갓생메이커 가입 유도

## 6. 사용자 여정 (User Journey)

```
1. 랜딩 페이지 접속
   ├─ [비로그인] MET 검사 → 결과 → SNS 공유 → 가입 유도
   └─ [로그인] Google OAuth

2. 첫 방문
   ├─ AI 코치 자동 팝업 (1.5초 후)
   └─ "안녕! 오늘 하루 어때?" → 자연스럽게 온보딩

3. 매일 아침
   ├─ 앱 열기 → "하루 계획하기" 버튼
   ├─ AI: 어제 점검 → 장기 목표 상기 → 오늘 확정
   └─ 운명 네비게이터 자동 채워짐

4. 매일 오후/저녁
   ├─ (향후) 알림 수신 → "하루 보고하기" 버튼
   ├─ AI: 목표 점검 → 하루 이야기 → 서신 채우기
   └─ 셀프 서신 + 머니 플로우 자동 채워짐

5. 주기적
   ├─ 100일 프로젝트 관리
   ├─ 규율 체크리스트
   └─ 주간/월간 목표 점검 (AI가 자연스럽게 유도)
```

## 8. 모듈 연동 맵

```
         ┌──────────────────┐
         │   AI 갓생코치     │  ← 모든 모듈의 관문
         │  (Floating Chat)  │
         └──────┬───────────┘
                │
    ┌───────────┼───────────┬──────────────┐
    ▼           ▼           ▼              ▼
┌────────┐ ┌────────┐ ┌─────────┐  ┌──────────┐
│ 운명    │ │ 셀프   │ │ 규율    │  │ 머니     │
│ 네비    │ │ 서신   │ │ 마스터리│  │ 플로우   │
│ 게이터  │ │        │ │         │  │          │
└───┬────┘ └────────┘ └─────────┘  └──────────┘
    │
    ▼
┌────────┐
│ 100일   │
│ 프로젝트│
└────────┘
```

대화 한 번으로 여러 모듈이 동시에 채워짐:
- "오늘 커피 사면서 친구 만났어" → 머니(커피 지출) + 서신(감사:친구)
- "이번 주 운동 3회 목표야" → 운명(주간 목표) + 규율(운동 규칙)
